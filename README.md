# CodeAlpha Tasks Repository

Welcome to the **CodeAlpha Tasks** repository! This repository contains web development projects completed as part of the CodeAlpha internship. Each project demonstrates core frontend development skills including HTML5, CSS3, JavaScript (DOM manipulation, LocalStorage, event handling), and responsive UI design.

## 🚀 Projects Included

### 1. 🎴 Flashcard Quiz App (`CodeAlpha_FlashcardQuizApp`)
An interactive flashcard management app that lets users create, review, edit, and delete flashcards for custom study topics.

* **Key Features:**
  * Create custom flashcards with questions and answers.
  * Interactive 3D flip card effect on click.
  * Inline editing and deletion of flashcards.
  * Persistent storage using browser `localStorage`.
* **Tech Stack:** HTML5, CSS3 (3D transforms & animations), JavaScript (ES6+).

---

### 2. 🌐 Multi-Language Learning App (`CodeAlpha_LanguageLearningApp`)
A interactive vocabulary practice and quiz tool designed for learning different languages.

* **Key Features:**
  * Support for multiple languages: **Tamil, Malayalam, Hindi, Japanese, Telugu, Chinese, and Korean**.
  * Interactive flashcards for vocabulary building.
  * Multiple-choice quiz section with instant feedback and score tracking.
* **Tech Stack:** HTML5, CSS3, JavaScript (DOM & State Management).

---

### 3. 💬 Random Quote Generator (`CodeAlpha_RandomQuoteGenerator`)
A clean, elegant web application that generates random inspirational quotes at the click of a button.

* **Key Features:**
  * Displays random inspirational quotes along with author names.
  * Simple and modern user interface.
  * Smooth transitions and button feedback.
* **Tech Stack:** HTML5, CSS3, JavaScript.

## 🛠️ How to Run Locally

You don't need any complex build tools or dependencies to run these projects. Follow these simple steps:

1. **Clone or Download the Repository:**
   ```bash
   git clone https://github.com/your-username/CodeAlpha_Tasks.git
   ```

2. **Navigate into the Repository:**
   ```bash
   cd CodeAlpha_Tasks
   ```

3. **Open Any Project:**
   Open the `index.html` file of any project folder directly in your preferred web browser:
   * Double-click `CodeAlpha_FlashcardQuizApp/index.html`
   * Double-click `CodeAlpha_LanguageLearningApp/index.html`
   * Double-click `CodeAlpha_RandomQuoteGenerator/index.html`

*Alternatively, you can use the **VS Code Live Server** extension to launch the projects.*
